# Currency Telegram Bot

Telegram-бот, который находит код валюты во входящем сообщении и показывает её курс относительно доллара США.

## Статус

Проект находится в разработке.

На текущем этапе реализован минимальный HTTP-сервер на Fastify с маршрутом проверки состояния приложения.

## Технологии

- Node.js
- TypeScript
- Fastify
- pnpm

## Требования

- Node.js 22+
- pnpm 11+

## Установка

```bash
pnpm install
