# Архитектурные диаграммы C4

- [System Context](./context.md) — пользователи, исследуемая система и внешние системы.
- [Container](./container.md) — единственный развёртываемый Fastify Backend и его окружение.
- [Component](./component.md) — внутреннее устройство backend и направления зависимостей.

Диаграммы последовательно переходят от общего контекста системы к контейнеру и затем к подробным компонентам одного процесса.
